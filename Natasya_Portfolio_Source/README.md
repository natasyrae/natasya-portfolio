# Natasya's Curiosity Studio

An original, responsive, buildless portfolio based on the supplied ATS CV. Open `dist/index.html` or serve `dist/` with any static web server. No third-party scripts, fonts, tracking, APIs, or build dependencies.

The isometric studio is drawn with Canvas. Visitors can click its four destinations or move the character with arrow keys, WASD, or the touch controls. Four discoveries earn a local explorer badge. Project case studies contain clearly labeled miniature interactive recreations, not links to the original projects. Original CV download is included.

Features: English interface, project filters and case studies, inventory simulator, educational RSA demo using BigInt, train search demo, interactive banking prototype, responsive design, reduced motion support, accessible dialogs, and keyboard navigation. Preferences and discoveries are saved on this device only, with a reset option. Contact links open the visitor's own email app.

All biographical claims and project dates are grounded in the supplied CV. The site does not invent repositories, live project URLs, client testimonials, or academic results. Demo transactions and train services are illustrative.

The experience section includes two supplied RAICOM photos and two original award certificate images. Click a thumbnail to open the gallery, use the arrow keys or navigation buttons to change images, and use Zoom in / Fit image to read certificate details. Original image downloads are available in each gallery.
